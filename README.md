# Towing Van Abuja – PWA

24/7 emergency towing Progressive Web App for Abuja.

## Features
- Large one-tap Call button
- Auto GPS + neighborhood name
- Send job details straight to WhatsApp
- Installable on Android & iPhone
- Install card **hidden** when already installed
- Compressed images + offline support
